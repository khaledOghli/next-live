## Registry helpers

| Export | Purpose |
|---|---|
| `defineLoader(fn)` | Mark a dynamic import as lazy loader |
| `defineModule({ default, exports })` | Explicit module record when default is ambiguous |
| `createRegistry(...groups)` | Merge registry groups |
| `registryFromGlob(glob, toSpecifier)` | Build loaders from `import.meta.glob` |
| `precompiledTransform(result)` | Client transform for server-precompiled code |
