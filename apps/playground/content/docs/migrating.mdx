Component names are deliberately the same — most of a migration is mechanical. The one real change: **`scope` becomes a module registry**.

## Imports

<CodeBlock code={`// react-live
import { LiveProvider, LiveEditor, LivePreview, LiveError } from 'react-live';

// next-live
import { LiveProvider, LivePreview, LiveError } from 'next-live';
import { LiveEditor } from 'next-live/editor';`} />

## scope → modules

<CodeBlock code={`// react-live — globals injected
<LiveProvider code={code} scope={{ useState, Button, formatDate }} />

// next-live — real imports in the snippet
<LiveProvider
  code={code}
  modules={{
    '@app/ui': defineLoader(() => import('@/components/ui')),
    '@app/format': defineLoader(() => import('@/lib/format')),
  }}
/>`} />

Snippet authors rewrite to:

<CodeBlock code={`import { useState } from 'react';
import { Button } from '@app/ui';
import { formatDate } from '@app/format';

export default function App() {
  const [n] = useState(0);
  return <Button>{formatDate(n)}</Button>;
}`} />
