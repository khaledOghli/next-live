    </AccordionContent>
  </AccordionItem>

  <AccordionItem value="empty-glob">
    <AccordionTrigger>My registry is empty and every import fails</AccordionTrigger>
    <AccordionContent>
      <CodeBlock code={`import.meta.glob('../modules/*.ts')   // ❌ empty, no warning
import.meta.glob('./modules/*.ts')    // ✅`} />
      Turbopack resolves globs relative to the calling file. Move the glob caller so the pattern points at or below its directory.
    </AccordionContent>
  </AccordionItem>

  <AccordionItem value="csp">
    <AccordionTrigger>CSP blocks eval</AccordionTrigger>
    <AccordionContent>
      Add `'unsafe-eval'` to `script-src` for runner routes in `proxy.ts`. A nonce will not help — `new Function` is governed solely by `'unsafe-eval'`. See [Security](/docs/security).
    </AccordionContent>
  </AccordionItem>

  <AccordionItem value="render-loop">
    <AccordionTrigger>Rendered more than 1000 times in 1000ms</AccordionTrigger>
    <AccordionContent>
      The render-loop breaker tripped. Look for `setState` during render or a `useEffect` without a dependency array. Editing the snippet clears the breaker on the next compile.
    </AccordionContent>
  </AccordionItem>

  <AccordionItem value="typescript">
    <AccordionTrigger>My TypeScript errors are not reported</AccordionTrigger>
    <AccordionContent>
      Types are stripped, not checked. Use your IDE and CI typechecking on snippet files if you store them as `.tsx` on disk. `validateSnippets` catches syntax and import errors only.
    </AccordionContent>
  </AccordionItem>

  <AccordionItem value="hooks">
    <AccordionTrigger>Do React hooks work in snippets?</AccordionTrigger>
    <AccordionContent>
      Yes. Snippets share your page's single React instance — the same reason a shared Zustand store works. Rules of Hooks apply normally.
    </AccordionContent>
  </AccordionItem>

  <AccordionItem value="hydration">
    <AccordionTrigger>Hydration mismatch #418 / #425</AccordionTrigger>

    </AccordionContent>
  </AccordionItem>
